# Mamlakatşunoslik (Country Study): interaktiv elektron ilovalar

Muallif: Jumayeva Dilbar Kuvondikovna, Navoiy davlat universiteti.

“Mamlakatşunoslik (Country Study)” darsligining 30 ta mavzusi uçun interaktiv ilovalar: rasmlar galereyasi,
atamalar kartoçkalari, xronologiya, diagrammalar, xaritalar, viktorina va test. Ilovalar internetsiz ham işlaydi.

- Boş sahifa: `index.html`
- Mavzular: `t01.html` … `t30.html` (darslikdagi QR kodlar şu sahifalarni oçadi)
- Avstraliya batafsil xaritasi: `t18_map.html`
- Töliq adabiyotlar röyxati: `Country_Study_Adabiyotlar_ilovasi.html` (`#t=18` kabi manzil tegişli mavzuni oçadi)

Sayt: https://jumayeva1983-ui.github.io/country-study-html/

Rasmlar öz litsenziyalari böyiça (har bir mavzudagi “Credits & sources” bandida körsatilgan).
